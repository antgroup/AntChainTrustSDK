# AntChainTrustSDK 1.1.0

## Release scope

This release packages the completed compatibility, platform, installation, and
bundle work after the `v1.0.0` baseline. It adds release automation and does
not claim hardware-backed security for the Linux, Android, or SIMCom reference
adapters.

## Compatibility

The release workflow compares public headers and installed symbols with the
previous stable tag. A removed or changed public API/ABI fails the release
rather than being silently classified as a minor release.

## Artifacts

Each Linux x86 bundle contains the installed SDK archive, license notices,
third-party manifest, SPDX SBOM, and a SHA-256 sidecar. Signing is delegated to
the configured CI signing command; no signing key is stored in this repository.

## Validation

Linux and cross-platform build gates are inherited from the existing quality
and platform workflows. AWS integration, target-device testing, and signing
remain explicitly gated by external credentials, devices, and CI configuration.
