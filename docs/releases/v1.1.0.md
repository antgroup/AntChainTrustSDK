# AntChainTrustSDK 1.1.0

Published on 2026-09-03 from tag `v1.1.0`, commit
[`eaf1136`](https://github.com/antgroup/AntChainTrustSDK/commit/eaf1136bb0bea3c68e9121a4f64775f906b858fb).
See the [changes since v1.0.0](https://github.com/antgroup/AntChainTrustSDK/compare/v1.0.0...v1.1.0)
and [changelog](https://github.com/antgroup/AntChainTrustSDK/blob/develop/CHANGELOG.md).

## Notable changes

- Expanded public API contracts, platform adapters, asynchronous lifecycle
  handling, and KV v2 persistence.
- An installable CMake package and Linux x86 SDK bundle tooling, including
  dependency metadata, license notices, an SPDX SBOM, and SHA-256 checksums.
- Linux Debug/Release and sanitizer checks, Linux ARM and Android cross-build
  workflows, and versioned Doxygen documentation.
- Release metadata and API/ABI checks against a previous stable tag, a central
  `VERSION` file, and a signing hook that delegates key handling to CI.

## Artifacts and API documentation

This GitHub release currently has no uploaded binary assets, checksums, or
signatures. GitHub's automatically generated source archives correspond to the
tag; they are not validated SDK bundles.

The bundle tooling can produce an installed SDK archive, license notices,
third-party manifest, SPDX SBOM, and SHA-256 sidecar. Release assets should be
attached only after the release, package, compatibility, checksum, and configured
signing gates pass for this tag. No successful end-to-end release publication
run is recorded for v1.1.0.

API documentation is available in the
[public headers](https://github.com/antgroup/AntChainTrustSDK/blob/v1.1.0/include/actrust.h).
Run `doxygen Doxyfile` from a v1.1.0 checkout to generate
`docs/v1.1.0/html/index.html`; this release does not host an API documentation
site.

## Known limitations

- AWS/PKI integration, external-network tests, and target-device validation
  were not established by the cited host CI runs. Android and Linux ARM were
  cross-built; SIMCom hardware validation is not reported here.
- Sanitized host smoke tests and TSan coverage were not established by those
  runs. Hardware-backed security is not claimed for the reference adapters.
- Release compatibility checks had baseline-selection and declaration-parsing
  defects tracked in [#2](https://github.com/antgroup/AntChainTrustSDK/issues/2);
  these CI results do not establish complete API/ABI compatibility.
- Post-release fixes cover signing-key cleanup after failed initialization
  ([#3](https://github.com/antgroup/AntChainTrustSDK/issues/3)), preservation of
  AWS identity on credential access errors
  ([#4](https://github.com/antgroup/AntChainTrustSDK/issues/4)), and KV v2
  configuration and wire-size validation
  ([#5](https://github.com/antgroup/AntChainTrustSDK/issues/5)). These fixes are
  tracked under Unreleased in the changelog and are not included in `v1.1.0`.
